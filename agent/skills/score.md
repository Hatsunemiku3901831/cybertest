# Skill: 目标渗透价值评分

本 Skill 在 `search.md` 或 `basicsearch.md` 完成资产建模后运行，基于资产地图自动生成目标渗透价值评分，决定"值不值得深入渗透"。

本 Skill 不路由，由 Agent 在资产建模完成后自动调用。

---

## 1. 评分公式

```
综合得分 = (资产面 × 0.35) + (攻击面质量 × 0.40) + (可利用性信号 × 0.25)
```

每维度 1-5 分。综合得分 1-5 分。

---

## 2. 资产面评分

取以下三项指标的**最高分**。

| 指标 | 1 分 | 2 分 | 3 分 | 4 分 | 5 分 |
|------|:----:|:----:|:----:|:----:|:----:|
| 子域名数 | <10 | 10-30 | 30-80 | 80-200 | 200+ |
| 存活 Web 数 | <3 | 3-8 | 8-15 | 15-25 | 25+ |
| 唯一 IP 数 | 1 | 2-3 | 3-5 | 5-10 | 10+ |

**修正规则**：

- 存活 Web 虽少但全是 SPA → 至少升到 2 分（SPA = JS = 密钥/API 可挖）。
- 存活 Web 虽多但全是纯静态 HTML → 至少降 1 分。

---

## 3. 攻击面质量评分（权重最高）

每命中一项 +1 分，上限 5 分。

| 编号 | 条件 | 数据来源 |
|------|------|----------|
| Q1 | 存在 `dev`/`test`/`staging`/`uat`/`beta`/`gray`/`sandbox` 命名子域名**且存活** | 子域名枚举 + 存活探测 |
| Q2 | 存在独立证书的子域名（与主站非同泛域名） | TLS 证书 `shares_cert` 分析 |
| Q3 | 存在有"登录/注册/找回密码/忘记密码"功能的页面 | body_snippet / 页面标题 |
| Q4 | 存在 `api`/`gateway`/`open`/`sso`/`cas`/`oauth`/`auth`/`passport` 命名的子域名 | 子域名枚举 |
| Q5 | 存在 SPA（Vue/React/Angular/Next/Nuxt）且有 JS bundle 下载成功 | 指纹识别 + JS 下载 |
| Q6 | 存在历史 URL，且有老 CMS/老框架路径（`.asp`/`.aspx`/`.do`/`.action`/`.jsp`/`.php`/`.shtml`/`FCKeditor`/`eWebEditor`） | 历史 URL 分析 |
| Q7 | 存在 CNAME 到第三方（CDN/对象存储/SaaS/WAF），去重后至少 3 条 | DNS CNAME 分析 |
| Q8 | 存在相同网段但不同 HTTP 状态码的资产（如一个 IP 上有 200 和 403 共存） | IP 关系 + 存活探测 |
| Q9 | 存在历史证书中的 ORG 字段与主域证书 ORG 不一致 | 证书透明度分析 |
| Q10 | 存在历史 URL 中含 `.git`/`.env`/`.svn`/备份/归档文件命名（`.zip`/`.rar`/`.tar`/`.sql`/`.bak`/`backup`/`databackup`） | 历史 URL 分析 |

**评分映射**：

```
0 分 = 命中 0 条  → 大概率是纯静态站，攻击面极小
1 分 = 命中 1 条
2 分 = 命中 2-3 条
3 分 = 命中 4-5 条
4 分 = 命中 6-7 条
5 分 = 命中 8+ 条
```

---

## 4. 可利用性信号评分

从 3 分基准线开始，加分上限 +2，减分无下限。

### 4.1 加分区（+1 每条，效果取最多 +2，达到 5 分为止）

| 编号 | 信号 | 含义 |
|------|------|------|
| E1 | 前端 JS 中发现硬编码密钥/AppID/Secret/Token（排除公开 SDK AppID） | 可伪造签名，立即可利用 |
| E2 | JS 中发现 source map URL 且可访问，或 body 中含内联 source map | 源码暴露，攻击面完整可见 |
| E3 | 响应头暴露具体软件版本号（如 `Server: nginx/1.27.1`、`X-Powered-By: PHP/7.4.33`） | 可做 CVE 版本映射 |
| E4 | 401 响应含 `WWW-Authenticate: Basic` 或 `NTLM` 或 `Negotiate` | 可尝试弱口令/密码喷洒 |
| E5 | 响应头 `Access-Control-Allow-Origin: *` 且 `Access-Control-Allow-Credentials: true`，且同一主机存在 API | 可做跨域凭据窃取 |
| E6 | 页面/JS 中有微信登录/OAuth/OIDC/SAML 集成 | 可测 OAuth 绕过/state 重放/redirect_uri 劫持 |
| E7 | 有 Swagger/OpenAPI/GraphQL/Knife4j/YApi/Apifox 文档入口且可访问 | API 面完整可见 |
| E8 | 文件上传/下载路径存活且可匿名访问（302/401 不算"存活"） | 可测上传绕过/路径穿越 |

### 4.2 减分区（-1 每条）

| 编号 | 信号 | 含义 |
|------|------|------|
| D1 | 所有存活 Web 都是纯静态 HTML 页面，无 JS bundle | 无分析深度空间 |
| D2 | 全部 401/403，无任何可匿名访问的非登录内容 | 无入口 |
| D3 | CDN/WAF 覆盖所有存活资产，无法触及源站 | 绕过成本高，源站不可控 |
| D4 | 目标已在主流 SRC 平台开放超过 12 个月，且为热门厂商 | 表面高危已被交过 |
| D5 | 全部域名共享同一证书，且全部解析到同一 IP | 大概率单一虚拟主机，无独立系统可挖 |
| D6 | 存活 Web 仅 1-2 个，且内容为纯展示型（官网/品牌页/BBS 归档） | 功能少，攻击面窄 |

## 5. 决策矩阵

| 综合得分 | 决策 | 说明 |
|:--------:|------|------|
| **4.0-5.0** | 🟢 **立即深入渗透** | ROI 最高。优先做 JS 深挖 + 密钥提取 + 签名绕过 + 组合发现。 |
| **3.0-3.9** | 🔵 **先跑补充分析** | 先跑历史 URL 分析 + 全部 JS 下载 + Q1-Q10 复核。如果命中 E1-E8 任一条，升为深入渗透。 |
| **2.0-2.9** | 🟡 **1h 快速扫描** | 只做 JS 密钥扫描 + source map 检查。1h 内无 E 类发现 → 放弃。有 E 类发现 → 升级。 |
| **1.0-1.9** | 🟠 **存档，不渗透** | 写入目标库，等别人挖过一轮后（如 6 个月无高危被交）再回头。或等新子域名/新证书出现时重新评分。 |
| **0.0-0.9** | 🔴 **放弃** | 不存档。不占目标库空间。 |

---

## 6. 特殊规则

### 6.1 目标不可达时的降权

如果存活探测发现**所有 Web 均 timeout/不可达**：

- 无法回答 Q1/Q2/Q5 → 这些条目不评分（不扣分也不加分）。
- Q3/Q6/Q9/Q10 如果可由外部来源（Wayback/外部抓取）回答 → 正常评分。
- 资产面分数降 1 分（因为实际可攻击面为零）。
- 综合得分上限锁死在 2.9 分（无法进入"立即渗透"）。

### 6.2 目标"太热门"时的降权

如果 D4 触发（已在主流 SRC 开放 12+ 月且热门）：

- 可利用性减分从 -1 改为 -2。
- 决策降一档。原本"立即渗透"→"先跑补充分析"，原本"补充分析"→"1h 快速扫描"。

### 6.3 跨目标发现加分

如果分析 Agent 发现当前目标与之前已评分的目标共享以下特征：

- 同一第三方 CMS/框架供应商（如两个目标都用 PowerEasy）
- 同一外包开发者（如 JS 中 @Author 相同）
- 同一 CDN/WAF/云平台 CNAME

当前目标的可利用性评分 **额外 +1**（因为可以复用已有的利用经验/POC）。

## 8. 评分示例

### 匿名媒体平台 (`media.example.invalid`)

```
资产面: 4 (84子域 / 16存活 / 3IP)
攻击面质量: 5 (命中 Q1/Q2/Q3/Q4/Q5/Q6/Q7/Q10)
可利用性: 4 (E1+E6+E3+E5 加分, D3 减分)
综合: 4.4 → 🟢 立即深入渗透
```

### 匿名教育平台 (`college.example.invalid`，目标不可达)

```
资产面: 3 (52子域 / 16解析 / 3IP, 但因目标不可达降1分 → 2)
攻击面质量: 3 (命中 Q3/Q4/Q6/Q7/Q10, Q1/Q2/Q5 不可评分)
可利用性: 2 (E6+E1+E7 加分上限用足, D2-2 降分+ D6-1)
综合: 2.75 → 🟡 1h 快速扫描 (如果恢复可达: 3.65 → 🔵 补充分析)
```

### 纯静态企业官网

```
资产面: 1 (5子域 / 1存活 / 1IP, 静态站修正 → 降1分 → 1)
攻击面质量: 0 (命中 0 条: 无独立证书/无SPA/无历史/无第三方CNAME)
可利用性: 1 (3 - D1-1 - D5-1 = 1)
综合: 0.75 → 🔴 放弃
```

---

## 9. 注意事项

- 本评分针对**渗透价值**，不评估"能赚多少钱"。SRC 收入还受厂商定价、提交速度、是否已被交过等外部因素影响。
- E1 中的"硬编码密钥"必须排除公开 SDK 的 AppID（如微信 JS SDK 的 appId、腾讯验证码的 appId），这些不能伪造签名。
- Q8（同网段不同状态码）需要 IP 关系图已生成。如 IP 面缺失（目标不可达），该项标记为 `unscored`。
- 跨目标发现加分（6.3）需要跨目标资产库支持。首次运行时默认关闭。
